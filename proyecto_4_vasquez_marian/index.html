¿Qué es CSS?

Lenguaje de diseño grafico que se utiliza para definir la apariencia visual de los documentosescritos en HTML o XML. Sirve para el Diseño y estetica

¿Qué aprenderé en este curso?

Aprenderás desde los fundamentos hasta técnicas avanzadas de CSS3. Dominarás el diseño con Flexbox y CSS Grid, la creación de animaciones fluidas, el uso de variables personalizadas (custom properties), maquetación adaptable para dispositivos móviles y la optimización de estilos mediante preprocesadores como Sass.

¿Qué es CSS GRID?

Es un sistema de diseño bidimensional para CSS que permite estructurar páginas web dividiéndolas en filas y columnas. Facilita la creación de layouts complejos y adaptables de forma limpia y ordenada sin necesidad de recurrir a trucos de posicionamiento antiguos.
